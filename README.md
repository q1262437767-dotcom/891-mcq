# 891 选择题 1000 道 · 刷题器

在线打开：https://q1262437767-dotcom.github.io/891-mcq/

这是一个完全离线的单文件刷题页面（`index.html`，不依赖任何网络资源）。题库共 1000 道单选题：大气 650 道（刘红年《大气科学概论》第 3 版）、环境 350 道（方淑荣、姚红《环境科学概论》第 2 版），全部依据复习手册与笔记编写，每题附解析、知识点、章节与出处。

题目从还没做过的题里随机抽，做完 1000 道前不会重复。每题作答后立刻判对错并显示解析；答错的题自动进入错题集，可按章节筛选、重刷或移出。首页能看进度和正确率，「章节统计」会把最薄弱的 5 章排在最前。

进度只保存在当前浏览器的 localStorage（键名 `nj891_mcq_v1`）。换设备或清理浏览器数据前，请先用「导出进度」备份 JSON，之后再用「导入进度」恢复。页面适配手机竖屏单手操作和系统深色模式。

GitHub Pages 请从 `main` 分支的根目录发布。
