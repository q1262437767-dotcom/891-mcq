## 进度存在哪里

未登录时，进度只保存在当前浏览器的 localStorage（键名 `nj891_mcq_v1`），顶部状态是「未登录·仅本地」。没有网络，或者暂时连不上账号服务时，刷题不受影响，作答仍写在本机。

登录之后，同一份进度会同步到该账号在 Supabase 表 `mcq_progress` 里的一行，本机 localStorage 继续当作离线缓存。换手机或清理浏览器之前，也可以用「导出进度」备份 JSON，再用「导入进度」恢复。

页面自带 `vendor/supabase-js.min.js`，不从外部 CDN 加载脚本，所以题库页面本身可以离线打开。同步时才需要能访问 Supabase。浏览器里只用公开的 publishable key，不要把 `service_role` 或 secret key 写进这个仓库。

## 注册和登录

1. 打开页面顶部的「登录/注册」。
2. 填写邮箱和密码（至少 6 位），点「注册」或「登录」。密码登录是主路径，不依赖邮件应用里的魔法链接。
3. 新注册的邮箱可能需要先确认。请打开确认邮件里的链接，它会回到这个刷题页并带上登录状态。若手机上的邮件应用用另一个浏览器打开、页面没有自动登录，回到原来的页面用同一套邮箱和密码登录即可。
4. 登录后顶部显示邮箱、同步状态和「退出」。状态有四种：已同步、同步中、同步失败、未登录·仅本地。同步失败时进度仍留在本机，网络恢复后会再试。

登录时会把本机和云端进度合并，避免覆盖掉任何一边做过的题：

- 云端还没有记录时，上传本机进度。
- 两边都有时，`rec` 按题号取并集，不丢掉已做题目。同一题只要有一边首答正确就保留首答正确，作答次数 `n` 以及其他计数字段取较大值。
- `wrong` 取并集；如果某一边已经因为后来答对而从错题集移除（该题首答错误，且又做过至少一次，现在不在错题里），合并结果里也不再放回。
- 刷题范围 `filter`、当前题 `cur`、错题筛选 `wfilter` 用较新的那一份（比较 `updated_at`，相同则比较较大的 `revision`）。
- 合并后同时写回本机和云端。云端已经有行时，上传会把 `revision` 加 1。

之后每次作答都会在本机立即保存，并在登录状态下稍作合并后写入云端。退出只清除本机的登录状态，不删除刷题进度。
